# DÍA - Gestión personal de actividades

Aplicación de escritorio desarrollada en Java para organizar y gestionar actividades personales desde una interfaz gráfica.

## Descripción

DÍA es un proyecto de software orientado a facilitar la organización cotidiana mediante la gestión de tareas, eventos, recordatorios y categorías.

El proyecto fue desarrollado utilizando programación orientada a objetos y cuenta con persistencia de datos local.

## Funcionalidades

- **Inicio:** panel principal de la aplicación.
- **Tareas:** gestión de actividades pendientes.
- **Recordatorios:** organización de recordatorios personales.
- **Eventos:** administración de eventos.
- **Categorías:** clasificación de los elementos registrados.

## Tecnologías utilizadas

- Java
- Apache NetBeans
- Git
- GitHub

## Persistencia de datos

La aplicación utiliza almacenamiento local mediante serialización de objetos Java.

Los datos se almacenan en el archivo `dia.dat`.
